# EN Deneyim Merkezi Van 🎓

> **Keşfet, Deneyimle, Öğren!**  
> EN Deneyim Merkezi Van şubesinin modern, etkileşimli ve kapsamlı resmi web platformu.

---

## 🌟 Özellikler

- **Yeni Nesil Kütüphane & EN Box**: Bireysel ve sessiz odaklanma alanları, ergonomik çalışma istasyonları.
- **EN Hall**: Grup çalışmaları, seminer ve etkileşimli eğitim salonları.
- **Gölge Koçluk & VIP Eğitimi**: Birebir takip, 4 kişilik VIP sınıflar, kişiselleştirilmiş çalışma programları.
- **Türkiye Geneli EN Deneme Kulübü**: ÜçDörtBeş All Star ve önde gelen yayınlarla Türkiye sıralamalı deneme sınavları.
- **YKS & LGS Hazırlık**: Alanında uzman kadro, yapay zeka destekli gelişim analizi ve rehberlik.
- **Hızlı İletişim & Konum**: WhatsApp ve doğrudan arama entegrasyonu, harita ve yol tarifi.

---

## 🚀 Teknolojiler

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Stil & Tasarım**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animasyonlar**: [Motion](https://motion.dev/)
- **İkon Seti**: [Lucide React](https://lucide.dev/)
- **Build Aracı**: [Vite](https://vite.dev/)

---

## 🛠️ Kurulum ve Yerel Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install --legacy-peer-deps

# Geliştirme sunucusunu başlatın
npm run dev

# Canlı (Production) derlemesi alın
npm run build
```
